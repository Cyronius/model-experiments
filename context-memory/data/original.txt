# F-0006: program-memory-16kb

**Claim:** Core program memory is 16 KB. Python-unrolled loops, per-K template copies, and static per-TU copies of shared kernel bodies overflow it (`XAIE_INVALID_ELF`).

**What to do:** Use `range_`, pass K at runtime, mark shared bodies `inline` + `noinline`, build with `-Os`.

**Where it was found:** phlegm open_kernels/designs (commit history to 2026-09-03).

# F-0009: worker-stack-size

**Claim:** A worker stack of 0xD00 hangs with fp32 vector code. 0x1800 works.

**What to do:** Set the stack to at least 0x1800 for fp32 vector kernels.

**Where it was found:** phlegm open_kernels/designs (commit history to 2026-09-03).

**Disputed:** Q-0028: LLMNpuTest GEMV and elementwise workers ran at 0xD00, and Granite attention workers read NaN at 0x1800 and needed 0x3000 (raw/LLMNpuTest/2026-09-01-dma-l1-program-memory-limits-and-silent-faults.md, raw/OpenFlowLM-Next3/2026-10-19-oflm-iron-peano-aiecc-dma-traps-and-hangs.md).

# F-0014: aie-api-pitfalls

**Claim:** On device: aie_api int32->float `to_float` on 16 lanes gives NaN. int16 `bit_and` scalarises. `get_cycles()` is unlinkable under Peano. Static vars in core code are not zeroed.

**What to do:** Mask through a uint8 view. Zero statics yourself. Avoid `get_cycles()`.

**Where it was found:** phlegm open_kernels/designs (commit history to 2026-09-03).

# F-0038: elf-vs-classic-load

# F-0066: masked-softmax-lowest

**Claim:** Masked softmax scores must be bf16 `lowest`, not -inf, because the exp argument is `S*c - m*c` in fp32 and -inf stays -inf on a path that expects finite values.

**What to do:** Mask with `lowest`.

**Where it was found:** dit_fa trap 5.

# F-0101: ctx-switch-decode-sized

**Claim:** With decode-sized kernels (floor.cfg, 2026-09-02) a dispatch costs 0.23-0.25 ms back to back in one context and 0.65-0.79 ms when the previous dispatch used another xclbin context; silu_mul after a switch costs 0.29-0.37 ms.

**What to do:** Plan ~0.4-0.5 ms per switch between xclbins at decode sizes. 132 dispatches times ~0.45 ms was ~60 ms of a 208 ms 27B step. See Q-0006 for other figures.

**Where it was found:** decode_chain/floor.cfg, driver `runlist` and `runx`.

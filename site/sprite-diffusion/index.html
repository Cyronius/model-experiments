About this experiment

A 24.2M-parameter rectified-flow transformer generates RGBA sprites from eight category labels. It does not follow text prompts. Sampling uses EMA weights, CFG 3 and Euler integration. This generator uses the 150k checkpoint.

Some outputs have incomplete shapes, stray pixels or smooth shading. Creatures favor people. Terrain is not guaranteed to tile. These are starting points to select and edit, not a promise of finished game assets.

Model weights and code are licensed under Apache 2.0. No training data is included.

Use Chrome or Edge with WebGPU for acceleration. The CPU fallback is slower. Generation speed and availability depend on your browser and hardware.

Model experiments

Small, cheap experiments with language models, mostly aimed at shared-memory hardware: CPU and iGPU boxes with no discrete GPU. Failures are written up as carefully as the wins.

Successful experiments

Qwen3.6-27B-A2.8B

Qwen3.6-35B-A3B with 10 of its 40 layers removed, then healed with a LoRA run. The heal recovered the quality the cut lost. It keeps the multi-token-prediction (MTP) draft head for speculative decoding.

  • 16.5 / 12 GB GGUF, from 22.9 GB Q4
  • $53 LoRA heal
  • ~$80 total cloud spend
Write-up Code Hugging Face

Qwen3.8-Flash-Next-131B-A6B

Qwen3.8-Flash-Next spends 51B of its 176B parameters on a hash table of bigrams and trigrams. Removing 87.5% of that table, and nothing else, keeps tool use, GSM8K and MMLU at parity with the full 90 GB quant. No training at all.

  • 64.8 GB GGUF, from 90 GB Q3
  • 0 training steps
  • $8 total cloud spend
Write-up Code Hugging Face

The two prunes reached nearly opposite conclusions one model generation apart. On Qwen3.6, layer pruning was survivable and cheap healing recovered it. On Qwen3.8, the same layer cut was fatal without healing, but most of the n-gram table came out for free.

titler

A tiny model that turns a prompt into a short title, so a chat app does not need a general-purpose LLM for the job. It is a standard Llama-architecture GGUF with a Rust engine and C, Python, npm and WebAssembly packages.

  • 4 MB GGUF
  • 5.8M parameters
  • 15–100 ms on a CPU

In progress

Manifold compression

Project a big model's activations onto a smaller architecture. A Qwen3.5 2B → 0.8B projection beats the stock 0.8B on perplexity, but it loops in open-ended generation.

ASD-STE100 rewriter

A tiny editor model that rewrites English into Simplified Technical English. The lexicon, checker and training data are done. The model is not built yet.

Ternary embedder

A text-embedding model with ternary weights, sized for the Strix NPU. It matches all-MiniLM-L6-v2 on STS and trails it on retrieval.

NPU kernel coder

Fine-tune a small open MoE to write AMD XDNA2 NPU kernels. Scoping only.

Failed experiments

Mixture of Widths

Nested variable-width MLPs with a router did not beat a plain fixed width at any compute level. Mixture-of-experts was not beaten either.

Post-training ternary quantization

Every post-training method tried on Qwen3-1.7B collapsed the model. Prism's Ternary-Bonsai keeps its quality because it was fine-tuned, not rounded.

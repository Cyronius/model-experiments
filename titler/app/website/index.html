titler

A 4 MB model that turns a prompt into a short title. It runs in your browser. Nothing you type is sent anywhere.

Loading the model (4 MB)…
Ctrl + Enter
Your title appears here.

The model has 5.8 million parameters and a 4 MB file (Llama architecture, 4-bit quantized). The browser runs it on the CPU through WebAssembly, with the same tokenizer and decoding code as the titler command-line tool.
